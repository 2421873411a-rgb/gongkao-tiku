# 实务处理题范式（综应）

> **数据基础**：24道真题。子类型：谈话沟通类、应急应变类、活动组织类。

## 一、题型本质
要求面对特定工作情境（群众投诉/突发事件/组织活动），提出处理方案。
核心：**情境代入 + 流程化处理**。

## 二、三大子类范式

### 1. 谈话沟通类（11题）
情境：领导安排你与XX谈话/沟通。
框架：
```
[准备]：了解情况，明确目标。
[实施]：
  1.表明来意，拉近距离。
  2.倾听诉求，记录要点。
  3.解释政策，疏导情绪。
  4.提出建议，达成共识。
[后续]：跟进落实，反馈结果。
```

### 2. 应急应变类（8题）
情境：突发XX事件，你如何处理。
框架：
```
1.迅速反应，控制局面。（止损）
2.了解情况，研判风险。（调查）
3.分类处置，妥善应对。（处理）
4.总结反思，完善机制。（预防）
```

### 3. 活动组织类（7题）
情境：组织XX活动/调研/培训。
框架（事前-事中-事后）：
```
[事前]：制定方案（目的/时间/地点/人员/预算），下发通知，做好准备。
[事中]：组织实施，协调各方，处理突发。
[事后]：总结评估，整理材料，汇报归档。
```

## 三、评分要点
1. **流程完整**：事前+事中+事后/准备+实施+后续
2. **角色得当**：符合身份权限
3. **措施可行**：具体可操作，不空泛
4. **轻重缓急**：应急题要先止损后处理
