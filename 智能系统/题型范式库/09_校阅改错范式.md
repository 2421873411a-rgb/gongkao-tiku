# 校阅改错题范式（综应）

> **数据基础**：32道真题。平均10.0个错误点（要点最多的题型）。

## 一、题型本质
给定一段文字（通常有8-10处错误），要求找出错误并改正。

## 二、常见错误类型
1. **错别字**：同音字/形近字混用
2. **用词不当**：词语搭配错误
3. **语法错误**：成分残缺/语序不当/句式杂糅
4. **逻辑错误**：前后矛盾/因果不当
5. **标点错误**：标点使用不规范
6. **常识错误**：事实/政策表述错误

## 三、答题框架
```
第X处："错误原文"改为"正确表述"。（错误类型：xxx）
```

## 四、找错技巧
1. 通读全文，逐句检查
2. 重点看：长句（易语法错）、专业术语（易常识错）、转折处（易逻辑错）
3. 改正时保持原意，只改错误部分

## 五、评分要点
- 找对位置 + 改对 = 满分
- 找对位置但改错 = 半分
- 漏找 = 不得分
