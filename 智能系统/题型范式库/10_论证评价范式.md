# 论证评价题范式（综应）

> **数据基础**：35道真题。平均4.0个论证错误。

## 一、题型本质
给定一段论证性文字，要求找出论证过程中的逻辑错误并说明理由。

## 二、常见论证错误类型
1. **概念混淆**：偷换概念、概念前后不一致
2. **以偏概全**：个别案例推出普遍结论
3. **强加因果**：先后发生≠因果关系
4. **类比不当**：两类不同事物简单类比
5. **绝对化**：表述过于绝对，忽略条件
6. **数据误用**：统计数据使用不当

## 三、答题框架
```
第X处：
A.错误位置："原文论证句"
B.错误类型：以偏概全/强加因果/...
C.理由：论证只依据XX，却推出XX结论，忽略了XX，因此论证不成立。
```

## 四、评分要点
1. **找对错误**（位置准确）
2. **类型正确**（判断错误类型）
3. **理由充分**（说明为什么不成立）
