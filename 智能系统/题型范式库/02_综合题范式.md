# 综合题范式

> **数据基础**：443道真题，442道含评分说明。平均2.7个层次。

## 一、题型本质

综合题要求对**一个观点/一句话/一个现象**进行全面分析，不是单一要素的概括，而是**多要素综合**。
核心特征：需要**整体理解+逻辑展开**，而非简单罗列。

### 子类型分布（数据验证）

| 子类型 | 特征 | 答题思路 |
|--------|------|---------|
| **词句解释题**（266题）| "谈谈对...的理解" | 总体释义+展开解释+总结 |
| **观点现象分析题**（68题）| "对...评价/评析" | 表态+理由+对策 |
| **对比分析题**（21题）| "比较A和B的异同" | 分别阐述+对比归纳 |

## 二、审题法则

### 词句解释题识别
- 题干："谈谈你对'...'的理解"/"解释'...'的含义"
- 核心：解释一句话/一个词的深层含义

### 观点现象分析题识别
- 题干："请对...进行评价/评析/谈谈看法"
- 核心：表态（正确/错误/辩证）+ 分析理由

## 三、答题框架

### 框架一：词句解释题三段式（266题验证）

数据揭示：442条评分说明中，**"总体释义+展开解释+总结"出现246次**——这是词句解释题的标准范式。

```
[总体释义]（50字）：解释这句话的字面/深层含义。
[展开解释]（200字）：
  一、[方面1总括]。
    1.[要点]。2.[要点]。
  二、[方面2总括]。
    1.[要点]。2.[要点]。
[总结]（50字）：回扣题目，提升高度。
```

**示例**（来自真题）：
> "这句话指出了精准扶贫改变了村民命运，让村民在物质和精神方面都发生了变化。
> 一、实现经济富有。1.由生活贫困变为脱贫...2.由发展落后变为产业兴旺...
> 二、实现精神富足。1.由见识短浅变为视野开阔...2.由消极懈怠变为信心增加...
> 综上，精准扶贫实现了物质与精神的双重改善。"

### 框架二：观点现象分析题三段式

```
[表态]：这一观点是正确的/错误的/需要辩证看待的。
[理由]：
  一、[理由1总括]。[分析说明]。
  二、[理由2总括]。[分析说明]。
[对策/总结]：因此，应该...
```

## 四、找点规则

### 词句解释题的找点逻辑
1. **拆解句子**：把目标句拆成几个关键词，分别解释
2. **回材料找对应**：每个关键词在材料中的具体表现
3. **分层归类**：按维度归类（如"物质层面/精神层面"）

### 特殊技巧：承接语
数据显示，优秀答案会使用"**变化表现**""**原因在于**""**体现在**"等承接语来清晰标注层次。

## 五、加工法则

### 1. 总分总结构（强制）
- 开头一句总体释义（不是直接展开）
- 中间分层次展开（通常2-3个方面）
- 结尾一句总结提升

### 2. 层次分明
每个方面用"一、二、三"标注，方面内用"1.2."细分。

### 3. 字数控制
总分300-400字：释义50+展开200-300+总结50。

## 六、评分标准

### 官方评分逻辑
：思路方面，本参考答案按照词句解释题“总体释义+展开解释+总结”的一般答题思路展开。内容
方面，本参考答案先对划线句子的含义进行了解释，接着展开解释了“‘人的变化’的具体表现”与“‘人的变化’的原
因”，最后结合资料逻辑进行总结。词句表达方面，本答案加上了“变化表现”“原因在于”等表述来承接上下文。

### 扣分点
1. **缺少总体释义**：直接展开，没有先解释句意
2. **缺少总结**：展开完不回扣
3. **层次混乱**：方面之间有交叉
4. **脱离材料**：主观臆断，不依据材料

## 七、常见错误

| 错误 | 表现 | 修正 |
|------|------|------|
| 当成单一题做 | 只罗列要点，没有释义和总结 | 严格三段式 |
| 释义太长 | 总体释义写了100字 | 控制在50字内 |
| 方面交叉 | "经济方面"和"产业方面"重叠 | 按MECE原则分类 |
| 忘记总结 | 展开完就结束 | 加一句回扣提升 |
