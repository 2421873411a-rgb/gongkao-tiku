# 题型范式库

> 从4886道真题中提炼的16种题型答题范式与经验法则。

## 范式总览

每篇范式文档包含8个模块，确保**精准、科学、全面**：
1. **题型本质** — 这题考什么、与其他题的区别
2. **审题法则** — 题干特征词→题型/要素判断（数据验证的映射表）
3. **答题框架** — 从参考答案提炼的结构模板
4. **找点规则** — 标志性词汇→要素类型映射
5. **加工法则** — 总括词前置/MECE/字数/规范词
6. **评分标准** — 从"参考答案说明"提炼的扣分点
7. **真题示例** — 典型题解析
8. **常见错误** — 考生易犯错误+修正
