# 单一题范式

> **数据基础**：1745道真题，1740道含官方评分说明。平均4.5个要点。

## 一、题型本质

单一题是申论的**基础题型**，要求从材料中概括**单一要素**（问题/原因/影响/对策/经验/启示等）。
"单一"指只需回答**一种要素**，而非只写一条。

### 要素分布（数据验证）

| 要素 | 出现频次 | 典型题干 |
|------|---------|---------|
| 对策/措施/建议 | 1264次 | "请概括XX的主要措施" |
| 问题 | 904次 | "指出XX存在的问题" |
| 影响/意义/作用 | 962次 | "分析XX的影响" |
| 原因 | 309次 | "分析XX的原因" |
| 经验/启示 | 181次 | "概括XX的经验启示" |
| 成效/变化 | 100次 | "总结XX的成效" |

## 二、审题法则

### 题型识别
题干出现"**概括/归纳/总结/分析/指出/说明**" + **单一要素词**（问题/原因/影响/对策/措施/经验/启示/变化/特点/优势）。

### 要素锁定（最关键）
审题时必须明确"**找什么**"，这决定找点方向：

| 题干指令 | 要素类型 | 找点方向 |
|---------|---------|---------|
| "概括...问题" | 问题 | 找负面表述（不足/缺失/困难） |
| "分析...原因" | 原因 | 找因果词（由于/导致/因为） |
| "总结...影响/意义" | 影响 | 找积极/消极结果 |
| "概括...措施/对策" | 对策 | 找动词句（完善/加强/推进） |
| "指出...经验/启示" | 经验启示 | 找成功做法 + 可借鉴处 |

### 材料范围锁定
- "根据资料X" → 只看资料X
- "结合全部资料" → 通读全部

## 三、答题框架

### 标准结构：分条并列式

```
1.[总括词]。[展开说明，来源材料的具体内容]。
2.[总括词]。[展开说明]。
3.[总括词]。[展开说明]。
4.[总括词]。[展开说明]。
```

**核心法则**：
- 每条以"**总括词**"开头（2-6字的规范短语，如"完善制度建设"）
- 总括词后跟展开说明（来源材料的具体表现，50-70字）
- 各条之间**内容并列，没有交叉**（MECE法则，1642条答案明确强调）

### 特殊变体：问题+对策对应式

当题目要求"指出问题并提出建议"时（2168题），采用：

```
问题：
1.[问题总括]。[具体表现]。
2.[问题总括]。[具体表现]。
建议：
1.[对策总括]。[具体做法]。（对应问题1）
2.[对策总括]。[具体做法]。（对应问题2）
```

## 四、找点规则

### 三种找点方法（数据频次）

1. **直接摘抄**（适用65%题目）：材料中有规范表述，直接提取
   - 重点看：段落首尾句、观点句、政策句
2. **概括归纳**（适用30%题目）：材料口语化/冗长，需压缩
   - 把"村长说他们村搞了个合作社大家一起种地赚钱"→概括为"发展合作社，实现规模经营"
3. **分析推导**（适用5%题目）：材料只给问题，需反推对策
   - "问题推对策"：缺制度→完善制度；缺资金→加大投入

## 五、加工法则

### 1. 总括词前置（强制规范）
❌ 错误："政府出台了很多政策来支持，比如给钱、给人、给技术"
✅ 正确："**强化政策支持**。出台扶持政策，提供资金、人才、技术保障。"

### 2. MECE去重（核心评分点）
检查各要点是否有内容重叠：
- ❌ "1.加强监管 2.完善管理" → 交叉（监管属于管理）
- ✅ "1.加强事前审批 2.强化事中监管 3.完善事后追责" → 不交叉

### 3. 规范词替换
口语化 → 规范化：
| 口语 | 规范 |
|------|------|
| "搞活动" | "开展宣传" |
| "定规矩" | "完善制度" |
| "找问题" | "排查隐患" |
| "帮老百姓" | "服务群众" |

## 六、评分标准

### 官方评分逻辑（从参考答案说明提炼）

：本参考答案分为“问题”和“建议”两个部分。其中，“问题”部分从“缺乏权益保障”“缺乏制度保
障”“职业发展困难”“难以融入社会”这四个方面展开；“建议”部分从“加强劳动监管”“完善制度保障”“优化企业管
理”“改善工作环境”“加强社会关怀”“发挥组织作用”这六个方面展开。各条答案要点之间在内容上相互并列，没有交
叉。

### 扣分点
1. **漏点**：每漏一个要点扣该点分值（通常每点3-5分）
2. **交叉**：要点内容重叠，重复部分不给分
3. **超字数**：超过规定字数通常扣1-2分
4. **口语化**：表述不规范酌情扣分

## 七、真题范式示例

### 示例题
**题干**：调研结束后，共青团H省委拟起草一份关于促进快递配送从业青年职业发展和社会融入的调研报告。假设你是该调研组成员，请根据“给定资料”，撰写调研报告中“问题”与“建议”这两部分内容的提纲。
**来源**：2020年国家公考《申论》题（副省级）

**参考答案结构**：分4条，每条"总括词+展开"，MECE不交叉。

## 八、常见错误

| 错误类型 | 表现 | 正确做法 |
|---------|------|---------|
| 要素混乱 | 题目问"问题"，答案混入"对策" | 严格锁定单一要素 |
| 总括词缺失 | 直接罗列材料原句 | 提炼规范总括词前置 |
| 要点交叉 | 多条内容重叠 | 按维度分类确保MECE |
| 照抄材料 | 大段抄原文不加工 | 概括压缩为规范表述 |
| 字数超标 | 超出规定字数 | 控制每点50-70字 |
