# 案例分析题范式（综应）

> **数据基础**：356道真题，218道含评分说明。平均3.8个要点。

## 一、题型本质

案例分析题是综应（事业单位）的**核心题型**（占356/1034=34%），本质与申论单一题/综合题相通：给定案例材料，要求分析概括。

### 与申论单一题的异同
| 维度 | 申论单一题 | 综应案例分析题 |
|------|-----------|--------------|
| 材料风格 | 政策性强，宏观 | 案例性强，微观具体 |
| 答题要素 | 单一要素 | 可含多要素 |
| 答案结构 | 分条并列 | 分条并列（同） |
| 平均要点数 | 4条 | 4.0条 |

## 二、审题法则

### 题型识别
题干通常：给定一个或多个案例 → 要求"概括/分析/归纳/谈谈"。

### 要素锁定
同单一题法则：根据题干动词确定找什么（问题/原因/影响/对策）。

## 三、答题框架

### 框架一：单一要素概括（同单一题）
```
1.[总括词]。[结合案例的具体表现]。
2.[总括词]。[结合案例的具体表现]。
```

### 框架二：问题+对策对应式（综应特色）
综应案例分析常要求"指出问题并提出对策"，采用对应结构：
```
问题：1.xxx 2.xxx
对策：1.xxx（对应问题1）2.xxx（对应问题2）
```

## 四、找点规则

### 案例材料的特点
- **具体事例多**：要从事例中提炼规律性要点
- **人物对话多**：从对话中提取观点/问题
- **数据细节多**：概括为定性表述

### 提炼方法
案例："王女士打电话感谢中心开通绿色通道..."
→ 提炼为："**优化服务方式**。开通绿色通道，实行容缺受理，提升服务效率。"

## 六、与单一题的答题差异

1. **更注重案例细节**：答案要体现对案例的理解，不能太空
2. **对策更具体可操作**：综应强调实务性，对策要落地
3. **角色意识更强**：常设定"假如你是XX工作人员"，答案要符合身份
