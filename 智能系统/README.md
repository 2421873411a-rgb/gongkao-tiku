> 从 **4886道真题** 中提炼的知识宫殿：题型范式 + 规范词大全 + 主题知识库 + 智能评判引擎。

## 系统总览

```
智能系统/
├─ 题型范式库/      14篇  ★ 16种题型的答题范式与经验法则
├─ 规范词大全/      6篇  ★ 700+规范词分类（对策/问题/影响/公文用语）
├─ 主题知识库/      11篇  ★ 10大主题的问题库+对策库+高频要点
├─ 评判系统/        3篇  ★ 规则评分引擎+评分标准+LLM评判Prompt
└─ 知识库索引/      4886条  ★ 全量题目的机读JSONL索引（多维标签）
```

## 🎯 这是什么

这是一座基于4886道真题（申论3852+综应1034）构建的**申论综应知识宫殿**，不是简单的文件堆砌，而是：
- 从每道题的**参考答案**提炼出规范表述
- 从每道题的**答题演示**提炼出三步法法则（审题→找点→组织）
- 从3427条**评分说明**提炼出MECE法则和评分维度权重
- 从8130个要点短语中提炼出分类规范词大全

所有法则均有**数据支撑**（标注出现频次），不是凭空编造。

## 🔍 Agent使用示例

### 检索某主题的题目
```python
import json
with open("知识库索引/questions_index.jsonl", encoding="utf-8") as f:
    questions = [json.loads(line) for line in f]
# 找乡村振兴+问题类题目
results = [q for q in questions if "乡村振兴" in q["themes"] and "问题" in q["elements"]]
```

## 🏗️ 建设方法

本系统全部通过**Python规则+统计**自动生成，不依赖LLM联网：
1. 数据提取：遍历4886题，提取多维标签（主题/要素/要点数）
2. 范式提炼：统计3427条评分说明，归纳6种答案模板和MECE法则
3. 规范词提取：正则抽取8130个要点短语，按动词分类
4. 主题聚类：按10大主题词库匹配，统计各主题高频要点
5. 引擎实现：基于规则的评分（要点匹配+格式检测+字数统计）

结果**可复现、可验证**，所有法则标注数据来源。
