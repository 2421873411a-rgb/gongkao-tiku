# 公文规范用语大全

> 从1105道公文写作题中提炼的公文规范用语。

## 一、标题规范

### 常见标题格式
| 文种 | 标题格式 | 示例 |
|------|---------|------|
| 倡议书 | 关于XX的倡议书 / 对仗式标题 | "全民参与 共建美好家园" |
| 通知 | 关于XX的通知 | "关于开展XX工作的通知" |
| 讲话稿 | 主题式标题 | "深化改革 推动发展" |
| 宣传稿 | 吸引式标题 | "XX，让生活更美好" |

## 二、称谓规范

| 受文对象 | 称谓 |
|---------|------|
| 普通群众 | "广大市民朋友们：" / "各位居民：" |
| 机关干部 | "各位同志：" / "全体干部：" |
| 与会人员 | "各位与会人员：" / "各位代表：" |
| 上级机关 | 尊敬的XX领导： |

## 三、开头（导入）规范用语

### 倡议书开头
- "为了...，特发出如下倡议："
- "当前...，我们呼吁..."

### 通知开头
- "为...，现将有关事项通知如下："
- "经研究，决定..."

### 讲话稿开头
- "各位XX，大家好！今天我发言的题目是..."
- "很高兴今天能在这里与大家交流..."

### 汇报/报告开头
- "现将XX工作情况汇报如下："
- "近年来，我区/我局..."

## 四、主体过渡规范用语

### 分条引导语
- "一是...；二是...；三是..."
- "首先...；其次...；再次...；最后..."
- "第一...；第二...；第三..."
- "（一）...（二）...（三）..."

### 逻辑承接语
- "与此同时..."
- "在此基础上..."
- "更为重要的是..."
- "不仅如此..."

## 五、结尾规范用语

### 倡议书结尾
- "让我们携手...，共同...！"
- "期待您的参与！"

### 通知结尾
- "特此通知。"
- "请遵照执行。"

### 讲话稿结尾
- "我的发言完毕，谢谢大家！"
- "让我们共同努力，为...贡献力量！"

### 报告结尾
- "特此报告。"
- "以上报告，请审示。"

## 六、落款规范

格式（右下角）：
```
                    发文单位名称
                    XXXX年XX月XX日
```

注意：日期用中文完整写法，如"二〇二四年三月十五日"或"2024年3月15日"。
