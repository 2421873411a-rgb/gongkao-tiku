# 规范词大全

> 从4886道真题参考答案中提炼的规范表述词汇库。

## 为什么需要规范词？

申论/综应评分的核心标准之一是"**规范准确性**"。用口语化的表述会被扣分，必须使用规范词汇。
例如：
- ❌ 口语："政府要管一管" → ✅ 规范："**强化监管**"
- ❌ 口语："搞活动宣传" → ✅ 规范："**开展宣传引导**"
- ❌ 口语："定个规矩" → ✅ 规范："**完善制度建设**"

## 使用方法

### 1. 答题时替换口语
查找本表，把口语化表述替换为对应规范词。

### 2. Agent调用
规范词总表.json可被Agent直接加载，用于：
- 答案规范度评分（检测是否使用规范词）
- 答案优化建议（把口语替换为规范词）
- 规范词推荐（根据主题推荐合适词汇）
