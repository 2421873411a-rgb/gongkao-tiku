# 评判系统

> 申论综应智能专家评判系统，支持规则引擎评分 + LLM精确评分。

## 组件

| 文件 | 功能 |
|------|------|
| [评分引擎.py](../../评分引擎.py) | 规则引擎：要点匹配+MECE+格式+字数+规范度 |
| [评分标准库.json](评分标准库.json) | 16题型的评分维度+权重+扣分细则 |
| [评判Prompt模板.md](评判Prompt模板.md) | 分题型的LLM评判Prompt |

## 快速开始

```bash
# 规则引擎评分演示
python 评分引擎.py --demo
```

## 评分流程

```
学生答案 + 标准答案
       ↓
  规则引擎评分（离线快速）
   ├─ 要点匹配（关键词重叠）
   ├─ 格式检测（正则）
   ├─ 字数统计
   └─ 规范度（规范词库）
       ↓
  基线得分 + 缺漏要点
       ↓
  LLM精确评分（可选增强）
   ├─ 要点语义匹配
   ├─ 立意/论据评价
   └─ 语言风格点评
       ↓
  最终评分 + 改进建议
```

## 维度权重（数据驱动）

权重来自3427条官方"参考答案说明"的统计分析：

| 题型 | 核心维度 | 权重 |
|------|---------|------|
| 单一题 | 要点完整性 | 60% |
| 综合题 | 要点+结构 | 50%+25% |
| 公文写作 | 内容+格式 | 40%+30% |
| 文章写作 | 立意+论据 | 30%+25% |

---
*基于4886道真题数据提炼。*
