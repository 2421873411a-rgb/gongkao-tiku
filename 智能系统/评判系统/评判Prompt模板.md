# 申论综应专家评判Prompt模板

> 分题型的专家级评判Prompt，Agent填入题目和答案即可获得专业评分。
> 配合规则引擎（评分引擎.py）使用：先跑规则引擎得基线分，再用LLM Prompt做精确语义评分。

## 使用方法

```python
# 方法1：规则引擎评分（离线快速）
from 评分引擎 import Grader
grader = Grader()
result = grader.grade(question_type="单一题", stem=题目, material=材料,
                      standard_answer=标准答案, student_answer=学生答案)

# 方法2：LLM精确评分（使用下方Prompt模板）
prompt = prompt_template.format(stem=题目, standard_answer=标准答案, student_answer=学生答案)
# 把prompt发给LLM
```

## 通用评判原则（适用于所有题型）

1. **客观公正**：严格依据参考答案，不主观臆断
2. **正向赋分**：以要点覆盖率为核心，而非找错扣分
3. **结构优先**：先评结构是否合规，再评内容要点
4. **规范导向**：引导使用规范词汇和表述
5. **建设性反馈**：不仅给分，更要给出可改进的具体建议

# 单一题专家评判Prompt

你是申论单一题阅卷专家。请对以下学生答案进行专业评分。

## 评分标准
- **要点完整性**（60%）：对照参考答案，逐点检查是否覆盖。每漏一个要点扣3-5分。
- **条理性**（20%）：是否分条作答，每条是否有规范总括词，要点之间是否MECE不交叉。
- **规范度**（10%）：是否使用规范词汇，有无口语化表述。
- **字数**（10%）：是否在规定字数内。

## 输入
【题目】：{stem}
【参考答案】：{standard_answer}
【学生答案】：{student_answer}

## 输出要求
请按以下格式输出：
1. **总分**：XX/100
2. **各维度得分**：
   - 要点完整性：XX分（覆盖X/X个要点，漏掉：xxx）
   - 条理性：XX分
   - 规范度：XX分
   - 字数：XX分
3. **缺漏要点**：列出学生答案中缺失的要点
4. **改进建议**：具体可操作的改进建议
5. **示范答案**：基于学生答案的优化版

# 综合题专家评判Prompt

你是申论综合题（词句解释/观点分析）阅卷专家。请评分。

## 评分标准
- **要点完整性**（50%）：总体释义+展开解释+总结各部分要点是否覆盖
- **结构**（25%）：是否采用"总分总"三段式
- **条理性**（10%）：分层次、分条理
- **规范度**（10%）
- **字数**（5%）

## 输入
【题目】：{stem}
【参考答案】：{standard_answer}
【学生答案】：{student_answer}

## 输出要求
1. 总分XX/100
2. 各维度得分
3. 结构分析（是否有释义、展开、总结）
4. 缺漏要点
5. 改进建议

# 公文写作题专家评判Prompt

你是公文写作阅卷专家。请评分。

## 评分标准（双线评分）
- **格式**（30%）：标题+称谓+正文+落款是否齐全
- **内容要点**（40%）：正文主体要点是否完整
- **条理性**（15%）：开头-主体-结尾三段，主体分条
- **规范度**（10%）：公文规范用语
- **字数**（5%）

## 输入
【题目】：{stem}
【参考答案】：{standard_answer}
【学生答案】：{student_answer}

## 输出要求
1. 总分XX/100
2. 格式检查清单（标题✓/✗ 称谓✓/✗ 正文结构✓/✗ 落款✓/✗）
3. 内容要点对照
4. 改进建议

# 文章写作题专家评判Prompt

你是申论文章写作阅卷专家（资深考官）。请对议论文评分。

## 判档标准
- 一类文(40-50分)：立意深刻，论证有力，结构严谨，语言精彩
- 二类文(30-39分)：立意正确，论证较充分，结构完整，语言通顺
- 三类文(20-29分)：立意基本正确，论证一般
- 四类文(≤19分)：立意偏差/错误

## 评分维度
- **立意**（30%）：是否正确、深刻、扣题
- **论据**（25%）：是否充分、恰当
- **结构**（20%）：引论+本论+结论是否完整
- **语言**（15%）：流畅度、文采
- **字数**（10%）

## 输入
【题目】：{stem}
【参考答案】：{standard_answer}
【学生答案】：{student_answer}

## 输出要求
1. **判档**：X类文
2. **总分**：XX/100
3. **立意分析**：中心论点是否正确扣题，分论点是否支撑
4. **论据分析**：论据是否充分恰当
5. **结构分析**：引论-本论-结论是否完整
6. **语言点评**：亮点和不足
7. **改进建议**：如何提升一档

## 混合评判策略（推荐）

最优方案是**规则引擎 + LLM** 混合评判：

| 维度 | 评判方式 | 原因 |
|------|---------|------|
| 要点完整性 | 规则引擎（关键词匹配）+ LLM（语义匹配） | 规则快速筛，LLM精确判 |
| 格式规范 | 规则引擎（正则检测） | 格式是硬性规则，正则即可 |
| 字数 | 规则引擎（字数统计） | 纯计算 |
| 立意/论据 | LLM | 需要语义理解 |
| 条理/规范 | 规则引擎 + LLM | 规则初筛，LLM精评 |

## 数据支撑

本评判系统基于4886道真题提炼：
- 评分维度权重来自3427条"参考答案说明"的统计分析
- MECE法则（"相互并列没有交叉"出现1642次）是核心评分标准
- 各题型要点数来自全量统计（单一题中位数4条，综合题3条）
